    Module Aggregator/ReaderIntelligenceGuide

    Description

    Language-aware, manifest-driven Reader Intelligence Guide component. Emits exactly one guide per article with all labels, descriptions, and section anchors translated into the article's language. Replaces the inline Markdown guide that was previously embedded in the aggregated document.

    The guide gives readers a navigation layer over the analysis artifacts behind the article, keyed to the article's H2 sections.
