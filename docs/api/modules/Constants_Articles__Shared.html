    Module Constants/Articles/_Shared

    Description

    Internal helper constants shared across multiple per-article-type modules. Not part of the public surface — re-export from the article modules if a consumer outside src/constants/articles/ ever needs them.

    AI-marker placeholders: every analysis text string in the per-article-type maps points at the same [AI_ANALYSIS_REQUIRED] sentinel that the article generator detects to force the AI agent to fill in real analysis prose.
