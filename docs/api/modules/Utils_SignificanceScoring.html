    Module Utils/SignificanceScoring

    Description

    5-dimension composite significance scoring engine for EP events.

    Scores each event across five dimensions (0–10 each) and computes a weighted composite score used for publication prioritisation decisions:

    Dimension Weight
    Parliamentary Significance 0.25
    Policy Impact 0.25
    Public Interest 0.20
    Temporal Urgency 0.15
    Institutional Relevance 0.15

    Decision thresholds follow the analysis template:

    Composite Decision
    0.0 – 3.4 skip
    3.5 – 5.4 hold
    ≥ 5.5 publish
