    Module Types/MCP/EPTools

    Description

    Option / result interfaces for the European-Parliament MCP one-shot tool calls exposed through EuropeanParliamentMCPClient (i.e. everything except the /feed endpoints, which live in ./ep-feeds.ts).

    Grouped here because each tool's option shape is small (≤ 10 fields) and individual per-tool files would add more import noise than they save.

    Transport types live in ./client.ts; report-generation tool options live in ./reports.ts.
